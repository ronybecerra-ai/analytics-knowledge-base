## Queries Team Analytics

**Objetivo**:
Centralizar las queries y lógicas utilizada en el team analytics

**Nomenclatura de cada carpeta**: 
Cada nueva solicitud o proyecto debería tener su propia carpeta con la siguiente nomenclatura: ANL-YYYY-NNN  

**Contenido mínimo por carpeta**:
- README.md
- Archivo.sql (ejemplo base_sorteo_viajes.sql)
